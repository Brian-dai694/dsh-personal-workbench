# 产品库：手动录入 + 界面重做（2026-10-31）

## 背景

「产品库」是亚马逊域里的独立入口，定位是**产品事实**（站点 / ASIN / 标题 / 价格 / 店铺 / 类目），
与「选品」（判断：结论 / 评分 / VOC / 下一步）分工，两页不互相显示对方的字段。

上一版（P3，2026-10-29）只做了"看 + 改"，没有"新增"：

- 标题栏只有「刷新」「生成表格并预览」；
- 行内只有一个 hover 才出现的「编辑」；
- 空库时的文案是"去选品页收藏或导入，这里就能看到" —— 而**选品页根本不往产品库写数据**。

于是产品库在空库状态下没有任何自举路径：用户打开就看到一句指向别处的话，也没有按钮。

同一天（2026-10-31 上午）后端先落了 migration 39：

```
products(id PK, site, asin, title, price, shop_name, category, created_at, updated_at, UNIQUE(site, asin))
```

注释写得很明确：**独立产品事实表；不回填、不读取、不修改选品库 `asin_products`**
（`test/productsRoutes.test.mjs` 里有一条断言钉住"选品表仍为 0 行"）。
本次就是把这条通道补完：客户端切过来 + 手动录入 + 界面重做。

## 数据模型边界（为什么是两张表，而不是一张表两个投影）

"选品"与"产品库"如果共用一行，产品库的写通道就必须碰 `verdict / score / judgment_json` 才
能写数据，P3 的边界（`test/productLibraryBoundary.test.mjs`）当场就守不住了。
两张表互不写入，边界是**物理的**，不靠"记得别写"。

代价是：从选品页跳到产品库**多半查不到那条**（两张表本来就无关）。这个代价用界面处理：

- 选品行 → 「产品库」按钮，带 `site + asin` 成对落地（只传 asin 会在多站点同 ASIN 时搜出两行）；
- 落地页没有这条时，空态给一个**预填好 ASIN / 站点**的「把「B0XXX」录入产品库」按钮，
  而不是让人回选品页抄 ASIN。

## API

`/api/workbench/products`（全部 loopback-only）：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/products` | `site/shop/category/q/page/size`；返回 `products / total / facets` |
| POST | `/products` | **手动录入**单条；重复键 409 + `code: 'duplicate'` |
| PATCH | `/products/:id` | 只改事实字段；身份字段（site/asin）出现即 400 + `code: 'immutable_field'` |
| DELETE | `/products/:id` | 第一次 200，第二次 404（不假装成功） |
| POST | `/products/import` | 批量导入（逐行 `created / duplicate / invalid`） |

`:id` 是 `站点_ASIN`，由仓储生成，前端原样回传 —— 用 id 而不是 `site+asin` 两个查询参数，
少一条"站点与 ASIN 不匹配"的分支。

口径细节：

- 站点先判"两位字母"再判长度（填 `USA` 应看到"必须是两位字母"，而不是"不超过 2 个字符"）；
- 价格 `''` → `null`，`0` 是合法价格（0 元不是"没填"）；
- 标题允许空串（还没维护标题是合法状态），店铺/类目空串 → `null`；
- 没有实质变化时**不推进** `updated_at`（否则点一次保存就把列表顺序打乱）；
- 分面计数按**全库**算（与选品页 `asinFacets` 同口径）：否则每次筛选下拉里的数字都在缩水。

## 界面（重做部分）

1. 标题栏三按钮：**手动录入**（主）/ 刷新 / 生成表格并预览；
2. 顶部计数条：产品 / 站点 / 店铺 / 类目（回答"我现在有多少东西"）；
3. 工具栏顺序固定：搜索 → 站点 → 店铺 → 类目 → 清空筛选（与选品页同一套控件与尺寸）；
4. 表格 7 列（事实 6 列 + 操作列），行内**常显**「编辑 / 删除」——
   旧版把编辑藏在 hover 里，触屏设备没有 hover，等于那台设备上永远改不了产品；
5. 删除是二次确认弹框，失败文案留在弹框里（关掉弹框再报错，用户不知道到底删没删）；
6. 分页带区间与每页条数（25/50/100）；
7. 重拉数据时表格只淡化、不撤掉（撤掉再长回来会闪）。

顺带修了两处共用样式缺失：

- `.wb-empty-title` / `.wb-empty-desc` 被 6 个视图用了很久但**一直没有样式**，空态看起来像加载失败；
- 新增 `.wb-btn.danger`（默安静，hover/focus 才用危险色，常驻红按钮会让"确认删除"显得像普通操作）。
