# 工作台视觉系统（2026-11-01 定案）

把"看起来舒服"翻译成**可抄的值**。所有值都从 DSH 宿主令牌派生，不另造一套色。
代码位置：`src/client/entryContract.ts`（色值映射）、`src/client/styles.ts`（令牌层）。

---

## 1. 颜色性格：量化色值

### 1.1 底色与层次

| 角色 | 令牌 | 浅色 | 深色 | 用法 |
|---|---|---|---|---|
| 画布 | `--wb-canvas` | **#F5F5F6** | #151517 | 面板背景（`96% bg-base + 4% ink-1` 混出） |
| 卡片 | `--wb-surface` | **#FFFFFF** | #232324 | 卡片、列表、统计块 |
| 浮层 | `--wb-bg-layer-2` | #FFFFFF | #2C2C2E | 弹窗、浮层 |
| 顶层 | `--wb-bg-layer-3` | #FFFFFF | #353638 | 菜单、下拉 |
| 凹陷 | `--wb-sunk` | = 画布 | = 画布 | 输入框、代码块 |

> 画布与卡片**必须差一档**（浅色 245 → 255）。两者同色时卡片没有悬浮感，
> 这是"卡片看着平"最常见的原因。

### 1.2 文字

| 角色 | 令牌 | 浅色 | 深色 | 对比度（浅色 / 白底） |
|---|---|---|---|---|
| 主文字 | `--wb-label-primary` / `--wb-ink-1` | **#0F1115** | #F9FAFB | 18.9:1 |
| 次文字 | `--wb-label-secondary` / `--wb-ink-2` | **#61666B** | #CFD3D6 | 5.9:1 |
| 三级文字 | `--wb-label-tertiary` | **#81858C** | #ADB2B8 | 3.9:1（只用于 ≥12px 的辅助信息） |

### 1.3 结构线

| 角色 | 令牌 | 浅色 | 深色 |
|---|---|---|---|
| 发丝线（分割） | `--wb-border-l1` / `--wb-line` | **#0000000A**（4%） | #FFFFFF0F |
| 常规边框 | `--wb-border-l2` | #0000001A（10%） | #FFFFFF1F |
| 强调边框 | `--wb-border-l3` | #0000001F（12%） | #FFFFFF29 |
| 虚化描边 | `--wb-line-quiet` | `ink-1` 15% | 同值派生 |

> 边框一律用**透明黑/透明白**，不要写 `#e5e7eb` 这类实色：换主题时实色不会跟着变，
> 深浅两套会打架。

### 1.4 强调与语义色

| 角色 | 令牌 | 浅色 | 深色 | 说明 |
|---|---|---|---|---|
| 强调（品牌） | `--wb-accent` | **#4176E6** | #7AAAFF | 直接取宿主 `state-business-primary`，全站唯一强调色 |
| 强调底（选中） | `--wb-accent-soft` | `accent` 12% | 同 | 选中行、轻填充 |
| 强调线 | `--wb-accent-line` | `accent` 38% | 同 | 选中描边 |
| 危险 | `--wb-danger` | **#EC1313** | #F25A5A | 删除、逾期 |
| 警告 | `--wb-warn` | **#F59E0B** | #F59E0B | 超重、待处理 |
| 成功 | `--wb-ok` | **#22C55E** | #22C55E | 完成、达标 |
| 信息/链接 | `--wb-info` / `--wb-link` | **#4176E6** | #7AAAFF | 与强调同源 |

**语义色不能当小字用**（对比不足）。文字要用"压一档"的 ink 档：

| ink 档 | 浅色 | 深色 | 推导 |
|---|---|---|---|
| `--wb-warn-ink` | **#8E6115** | #F59E0B | `50% warn + #27241F`，5.4:1 |
| `--wb-ok-ink` | **#147A3A** | #22C55E | `50% ok + #052E16`，5.4:1 |
| `--wb-danger-ink` | **#D11313** | #EC1313 | `88% danger + #0F0F0F`，5.5:1 |
| `--wb-info-ink` | **#345EB6** | #7AAAFF | `75% info + #0B1424`，6.1:1 |

### 1.5 分类色（不是状态色）

ABA 分层：头部 = 成功绿（值得做）、中部 = 强调蓝（可观察）、长尾 = 中性灰（弱）。
分类色与状态色**同色不同义**，所以单独命名（`--wb-tier-middle` / `--wb-tier-tail`），
不要在别处直接写 `--wb-ok`。

## 2. 三大视觉规则

### 2.1 留白透气：横向 16 / 纵向 16 或 24

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `--wb-space-x` | **16px** | 多列卡片左右、卡片内左右留白（严格固定） |
| `--wb-space-y-tight` | **16px** | 同一列卡片上下、网格行距、弹窗头/脚 |
| `--wb-space-y` | **24px** | 分区之间、页面内边距、弹窗内容体 |
| `--wb-sp-1..7` | 2 / 6 / 8 / 10 / 12 / 16 / 24 | **行内密集**元素（标签、徽标、表格单元） |

行高：**标题 1.25 / 紧凑列表 1.45 / 正文 1.6**（`--wb-lh-tight|snug|body`）。
中文在 12–13px 下 1.6 是不粘行的下限。

### 2.2 粗细反差：四档字重，相邻层级至少差一档

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `--wb-fw-body` | **400** | 正文、表格单元、说明 |
| `--wb-fw-emphasis` | **500** | 按钮文字、表头、元信息关键值 |
| `--wb-fw-heading` | **600** | 卡片标题、页签选中项、小标题 |
| `--wb-fw-display` | **700** | 面板标题、大数字 |

字号刻度：**12 / 13 / 14 / 16 / 20 / 24**（`--wb-fs-1..6`）。
元信息一律 12，正文 13，卡片标题 13–14，面板标题 16，大数字 20–24。
**层级差 = 字号差一档 + 字重差一档**；只有字号差、字重相同的两级看起来像同一级。

字间距：中文 **0**（加宽会散架）；全大写英文/型号串 `.02em`；大数字 `-.01em`。

### 2.3 平滑过渡：四档时长 + 两条缓动

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `--wb-dur-1` | **120ms** | hover、按下、颜色微变 |
| `--wb-dur-2` | **180ms** | 淡入淡出、颜色切换（页签未选中降亮度） |
| `--wb-dur-3` | **260ms** | 位移（指示条、日历选中块） |
| `--wb-dur-4` | **320ms** | 面板/弹窗进场 |
| `--wb-ease-standard` | `cubic-bezier(.4, 0, .2, 1)` | 本来就在动的东西（位移、颜色） |
| `--wb-ease-enter` | `cubic-bezier(.2, .8, .2, 1)` | 新出现的东西（先快后慢，落定更稳） |

页面切换与列表→详情用原生 View Transitions（`viewTransition.ts`），
`prefers-reduced-motion: reduce` 时全部关掉。

## 3. 字体搭配：Inter + 思源黑体怎么按字重分工

### 3.1 栈顺序就是分工

```css
--wb-font: "Inter", "Inter var", "Source Han Sans SC", "Noto Sans SC",
           "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
--wb-font-mono: ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, monospace;
```

浏览器**按字符**挑字体，不按语言切样式，所以：

- **Inter 管拉丁字母、数字、标点** —— x-height 大、数字等宽，型号 / 金额 / 百分比最整齐；
- **思源黑体管中文**（`Source Han Sans SC` 是正式名，`Noto Sans SC` 是它上 Google Fonts 的名字，同一套字形）；
- 再往后是系统中文兜底（PingFang / 微软雅黑），最后才是 `system-ui` / `sans-serif`。

### 3.2 字重对照（关键：两套字体的档位并不一一对应）

| 用途 | 令牌 | Inter | 思源黑体（静态） | 思源黑体（可变字体） |
|---|---|---|---|---|
| 正文 | 400 | Regular | Regular (400) | 400 ✓ |
| 强调/按钮 | 500 | Medium | Medium (500) | 500 ✓ |
| 卡片标题/选中页签 | 600 | SemiBold | **只有 Bold(700)** → 会偏重一档 | 600 ✓ |
| 面板标题/大数字 | 700 | Bold | Bold (700) | 700 ✓ |

**结论**：中文要真正对齐 600 档，必须用**可变字重**的思源黑体 / Noto Sans SC
（wght 100–900）。用静态字重时，600 会落到 Bold，"英文标题比中文标题轻一档"的现象就是这么来的。
装了静态版又想对齐，只有两条路：把中文标题也统一写 700（英文会显得更重），
或者给中文标题单独降到 500（层级反差又不够）。所以推荐 VF。

### 3.3 可执行清单

1. 装 **Inter VF** 与 **Noto Sans SC VF**（或思源黑体 VF），各取 wght 100–900；
2. 只在 `--wb-font` 里写一次栈，别在组件里另写 `font-family`；
3. 字重只用四个令牌（400 / 500 / 600 / 700），不许再写 550 / 650；
4. 数字对齐的列（金额、时长、计数）加 `font-variant-numeric: tabular-nums`；
5. 等宽场景（会话 id、关键词代码）用 `--wb-font-mono`，不要用 Inter 顶替。

## 4. 苹果官网口径的取舍（2026-11-01 第二轮）

苹果官网那套是**营销页**排版：图占 40%、字占 7%、模块间距 40pt+、页边距 6–8%。
工作台是**工具**：一屏要放 40 行任务。所以只迁移能迁移的部分，其余写明差异与理由。

### 4.1 已落地

| 苹果口径 | 落地方式 |
|---|---|
| 粗细极致对比 | 四档之外补 `--wb-fw-light: 300` / `--wb-fw-heavy: 800`；**Light 只许配 ≥20px 的字号**（12px 中文用 300 会糊成虚线），Heavy 只给 KPI 数字与大标题 |
| 字越小行距越大 | `--wb-lh-meta: 1.75`（12px 元信息）· `--wb-lh-body: 1.6`（13px 正文）· `--wb-lh-tight: 1.35`（14px 标题） |
| 左文右数 | KPI 卡片：数字 24px / **Heavy 800** / `--wb-ls-display: -.02em` / 行高 1.1；标签 12px / 400 / 三级灰 / 行高 1.75 |
| 数据区不画多余框线 | `.wb-stat` **去掉 1px 边框与投影**，改由「画布 #F5F5F6 vs 卡片 #FFFFFF」的灰度差分隔 |
| 半边换色 | 核心结论上色：`.wb-amazon-result-head strong` 用 `--wb-accent`（其余标题仍是主文字色） |
| 留白撑场面 | `--wb-space-section: 40px` 只用于**页面模块之间**（`.wb-dash` 行距），卡片内部仍是 24/16 |

### 4.2 明确不迁移（附理由）

| 苹果口径 | 为什么不照搬 |
|---|---|
| 正文 40pt / 数字 40pt | 40pt ≈ 53px。990px 面板里一个数字占掉 5% 宽度，KPI 行会从 4 个变 2 个 —— 信息密度是工具的第一需求。工作台取 **24px 数字 + 12px 标签**，比例关系（数字是标签的 2 倍）与苹果一致 |
| 图占 40% / 字占 7% | 工作台没有主视觉图；7% 的文字占比意味着"一屏只有两行字"，与任务列表的使用方式冲突 |
| 页边距 6–8% | 990px × 6% ≈ 60px。左右各 60px 会吃掉两列内容的宽度；工作台固定 **16px**（≈1.6%），靠卡片之间的留白而不是页边距透气 |
| 渐变光源（冷色/亮色渐变） | 面板与 DSH 宿主同色系，渐变背景会与宿主主题打架；渐变只保留在**语义色混色**（12% / 38% 档）里 |
| 提取色（#42A288 / #6C41E6） | 这两个色是"从产品图取色"的结果，属于品牌营销色。工作台的强调色必须与 DSH 品牌色一致（`#4176E6`），再引入第二套品牌色就是"两套色系"的老问题 |

### 4.3 一句话口径

> 苹果的比例关系（数字 2 倍于标签、字越小行距越大、少画线多留白）**照搬**；
> 苹果的绝对尺寸（40pt / 7% / 6–8%）**按工具密度换算**，换算系数约 0.6。
