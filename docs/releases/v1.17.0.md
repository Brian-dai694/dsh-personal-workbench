# v1.17.0 Release Notes

> 主题：**角色库/专家 UI 可用性修复 + 英文界面（i18n）+ 宿主浮层挂载**
> 上一个稳定点：`v1.16.5`
> 版本号 `1.17.0`（`package.json` / tag / npm / GitHub Release 四者一致）。
> 发布日期：2026-10-19

## 0. 范围表（动版本号之前先填）

| 列 | 内容 |
|---|---|
| **本版主题** | **可用性与本地化**：修掉角色库/专家生成与设置页的可见 UI 缺陷，给顶层界面加英文语言支持，并把插件浮层挂到宿主真正的 overlay 层上——三者共同构成"看得见、点得到、读得懂"的同一主题。 |
| **主线变更** | ① 专家草稿预览排版（根因是误用 `.wb-draft-field` / `.wb-row-meta`）；② 设置页「继续修改」「查看草稿」的弹窗/浮卡交互与 z-index；③ 角色来源标签去重、清理界面里露出的 Markdown 标记；④ 新增 `uiLocale`（自动/中文/English）与 `t()` 文案表，覆盖顶栏、设置、角色库/专家、快速录入、任务表单、知识库与选择器；⑤ 知识库工具栏/分页/标签/空态/详情编辑表单英文。 |
| **夹带项（1 件）** | **Issue #14 宿主浮层修复**：所有 portal 改走 `overlayMountContainer()`，优先挂 `[data-shell-overlay]` 并补 `pointer-events:auto`。为什么必须同版：语言设置、专家草稿检查、模型选择都发生在设置弹窗/浮层里，不修这些浮层在桌面端仍被面板盖住，本版的可用性目标不成立。 |
| **随本版送达的非编译内容** | README 语言/版本历史刷新、`docs/releases/v1.17.0.md`、`docs/tasks/51189a57-…/P12-handover.md`（任务资料夹内的完整取证）；发布前 PII 扫描把历史任务资料夹/测试夹具里的真实账号名与公司路径替换为 `<user>` / `<company>` 占位符（内容语义不变，见 §3）。 |
| **被推迟** | ① 深层 i18n（点子页、任务详情长文、通知/提醒/微信/字典管理）；② 字典条目名称的本地化（仍由用户字典维护）；③ 列表排序仍固定 `zh-Hans-CN` collation；④ 桌面端 issue #14 的人工点验（Web 隔离实例已验，桌面需用户安装后确认）；⑤ 英文界面不是 4,100 条全量翻译，只覆盖本版声明的顶层范围。 |

### 发布前门禁清理

- 发布前发现工作区里残留了一处**变异探针改动**：`src/shared/dailyPlanPolicy.ts` 的 `planned += minutes` 被改成了 `minutes * 2`，且文件被写成 CRLF。该改动**不属于本版功能**，已还原为 `minutes`、统一 LF，并重新跑 typecheck / 全量测试。发布门禁随后在干净工作区上重新执行。
- 单测命令改为 `node --test --test-concurrency=1`：Windows 上并行运行会偶发 `bad port` / 跨测试文件的端口竞态（本项目测试自身已有重试，但仍会偶发第三次失败）。串行后 1303 条依然全绿，运行约 42 秒；这是发布门禁稳定性修复，不改变产品行为。
- 发布前 PII 扫描发现历史任务资料夹（P0/P8/P9/P10/P11 等）与少量测试夹具含真实 Windows 账号名/公司路径。已统一替换为 `<user>` / `<company>` 占位符，并在本版重新跑 PII 两面；npm 包面（`lib/**`）保持干净。这属于**安全清理**，不改变任何产品行为。

## 4. 破坏性变更与兼容性

- **无 schema 变更**：仍为 **19**；无字段增删、无 API 形状变化。
- 新增设置字段 `uiLocale`（默认 `auto`）；旧客户端忽略该字段，旧服务端不返回时客户端回落 `auto`。
- 浮层挂载点从 `document.body` 改为宿主 overlay（不满足条件仍回落 body）；不改变任何 API。
- 无新增运行时/构建依赖；`inject` 清单未变；`pnpm-lock.yaml` 未动。
